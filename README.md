# NovaColor

Italiyaning **Novacolor** dekorativ devor qoplamalari uchun premium animatsiyali sayt (Toshkent).

🔗 Sayt: https://jahonsher.github.io/novacolor/

## Texnologiyalar

- React + TypeScript + Vite
- Tailwind CSS
- three.js (WebGL: hero shader, 3D kategoriya halqasi, rasm effektlari)
- GSAP + ScrollTrigger + SplitText (matn va skroll animatsiyalari)
- Lenis (silliq skroll)

## Ishga tushirish

```bash
npm install
npm run dev      # lokal: http://localhost:5173/novacolor/
npm run build    # production build
npm run deploy   # GitHub Pages'ga joylash (gh-pages branch)
```

Ma'lumotlar `src/data/content.json` faylida (mahsulotlar, kategoriyalar, yangiliklar, kontaktlar — UZ/RU).
